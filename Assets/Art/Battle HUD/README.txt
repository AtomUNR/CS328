Battle Tower HUD pieces

Each PNG is cropped directly from the original HUD mockup, retaining its artwork and text. Transparent pixels were made from the exterior dark background.

Unity setup: import the PNGs into Assets. Set Texture Type to Sprite (2D and UI). Set Filter Mode to Point for crisp pixel edges. Keep Compression off or None. Use Image components for the button and dialogue/status pieces. The dialogue and status art include the example text and values from the mockup, so they are visual references; rebuild those labels and changing HP/MP values with Unity UI Text/TMP for gameplay.
